# ESP32 Solar Smart Fan

## Overview

This project is a solar-powered smart fan system using ESP32.

Features:

* Solar charging system
* 2S 18650 battery pack
* PWM fan speed control
* Current and voltage monitoring using INA219
* OLED display
* Battery protection system
* Custom PCB design

---

## Hardware

* ESP32
* TP5100
* HX-2S-JH20
* IRLZ44N
* INA219
* OLED SSD1306
* LM2596
* 2×18650
* Solar panel
* DC fan
